# JEE Dropout Analysis Dashboard

## Live Dashboard
[View Tableau Dashboard](https://public.tableau.com/app/profile/om.shah7057/viz/Book1_17425059569650/Dashboard1)

## Project Overview
This project presents an interactive Tableau dashboard analyzing dropout patterns among JEE aspirants. The dashboard explores how factors such as family income, school board, coaching institute, study hours, location type, mental health, and state-level trends relate to dropout rates.

## Objective
The goal of this project is to identify key factors influencing JEE student dropout and present insights through interactive data visualization.

## Key Features
- State-wise dropout rate analysis using map visualization
- Dropout comparison by family income
- School board-wise dropout analysis
- Coaching institute comparison
- Study hours vs dropout trend
- JEE Main vs JEE Advanced score comparison
- Interactive filters for deeper analysis

## Key Insights
- Low-income students show significantly higher dropout compared to high and mid-income groups.
- Study hours are nearly similar across income groups, suggesting dropout is influenced by more than just study time.
- Dropout rates vary significantly across Indian states.
- School board type shows relatively small variation in dropout trends.
- Coaching institute type alone does not guarantee lower dropout.
